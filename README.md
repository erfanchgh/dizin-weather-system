# Dizin Weather Story

نسخه اولیه قالب استوری هواشناسی دیزین با نسبت 9:16.

## تغییر عکس پس‌زمینه

دو روش در نظر گرفته شده:

1. **از داخل خود صفحه:** روی دکمه «تغییر عکس پس‌زمینه» بزن و عکس را از گوشی انتخاب کن. پیش‌نمایش استوری همان لحظه با عکس جدید نمایش داده می‌شود.
2. **عکس دائمی پروژه:** فایل پیش‌فرض داخل `assets/background.svg` است. در نسخه نهایی می‌توانیم عکس اصلی دیزین را به‌صورت `assets/background.jpg` قرار دهیم تا همیشه همان تصویر نمایش داده شود.

## اطلاعات هواشناسی

داده سه روز در `data.js` قرار دارد. معیار ارتفاع روی قله **3599 متر** تنظیم شده و «دمای حسی»، باد و برف نمایش داده می‌شود. بارش باران عمداً حذف شده است.

در مرحله بعد دریافت و به‌روزرسانی خودکار اطلاعات از Snow-Forecast اضافه می‌شود.

## فایل‌ها

- `index.html` — ساختار استوری
- `style.css` — طراحی و چیدمان 9:16
- `data.js` — داده هواشناسی
- `app.js` — نمایش داده و تعویض عکس
- `assets/background.svg` — پس‌زمینه موقت
